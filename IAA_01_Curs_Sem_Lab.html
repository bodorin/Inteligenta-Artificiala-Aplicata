1. CursCURS

1.1 Ce este un agent?

Un agent este orice entitate care percepe mediul prin senzori și acționează asupra lui prin efectori (actuatori).

Exemple: un om (ochi, urechi → mâini, voce), un robot (camere, lidar → motoare), un program (fișiere, pachete de rețea, apăsări de taste → scriere pe ecran, trimitere de mesaje), un personaj autonom (NPC) dintr-un mediu virtual (poziția jucătorului, sunete, coliziuni → deplasare, dialog, animații).

Ce primește agentul la un moment dat se numește percepție; tot ce a primit până acum este secvența de percepții. Comportamentul agentului este descris de funcția agentului, care asociază fiecărei secvențe de percepții o acțiune:

f : P* → A

Funcția agentului este o descriere matematică, abstractă. Programul agentului este implementarea ei concretă, care rulează pe o arhitectură (hardware + senzori + efectori). Pe scurt: agent = arhitectură + program.

De ce nu implementăm funcția agentului direct, ca tabel? Pentru că tabelul are câte o intrare pentru fiecare secvență posibilă de percepții. Cu |P| percepții posibile și o durată de viață de T pași, tabelul are

Σt=1..T |P|t intrări

Pentru o cameră video modestă (|P| uriaș) și T de ordinul orelor, numărul depășește numărul de atomi din univers. Provocarea IA este să scriem programe mici care produc comportament rațional, nu tabele imense.

1.2 Comportamentul calitativ: raționalitate

Un agent se comportă „bine” dacă secvența de stări ale mediului pe care o produce este dezirabilă. Dezirabilitatea este măsurată de o măsură de performanță, stabilită de proiectant, nu de agent.

Un agent rațional alege, pentru fiecare secvență de percepții, acțiunea care maximizează valoarea așteptată a măsurii de performanță, ținând cont de percepții și de cunoștințele sale anterioare.

Raționalitatea depinde de patru lucruri: (1) măsura de performanță, (2) cunoștințele inițiale despre mediu, (3) acțiunile posibile, (4) secvența de percepții de până acum.

Proiectați măsura de performanță după ce vreți să se întâmple în mediu, nu după cum credeți că ar trebui să se comporte agentul. Un aspirator recompensat pentru „cantitatea de praf aspirată” poate învăța să verse praful înapoi și să-l aspire din nou.

Rațional ≠ omniscient ≠ infailibil

  • Omnisciența ar presupune cunoașterea rezultatului real al acțiunilor – imposibil în lumi reale. Raționalitatea maximizează performanța așteptată.
  • Colectarea de informații (acțiuni care modifică percepțiile viitoare – „mă uit înainte să traversez”) face parte din comportamentul rațional.
  • Învățarea: agentul trebuie să învețe din percepții cât mai mult; un agent care se bazează doar pe cunoștințele proiectantului nu are autonomie.

Problema specificării obiectivului (value alignment)

În IA modernă, măsura de performanță este rareori complet cunoscută. Russell (2019) propune ca agentul să fie incert asupra obiectivului și să deducă preferințele umane din comportament (assistance games, Inverse Reinforcement Learning cooperativ). Pentru proiect, reflectați: măsura voastră de performanță poate fi „păcălită” (reward hacking)? Ce efecte secundare nedorite pot apărea dacă este optimizată excesiv (legea lui Goodhart)?

„Cunoscut/necunoscut” se referă la starea de cunoaștere a agentului despre regulile mediului, nu la mediu. Distincția nedeterminist vs. stochastic: un model nedeterminist enumeră rezultatele posibile ale unei acțiuni; un model stochastic le atașează și probabilități.

1.4 Structura unui agent inteligent

Există cinci tipuri de bază de programe-agent, în ordinea crescătoare a generalității:

  1. Agent reflex simplu – reguli condiție → acțiune aplicate percepției curente. Funcționează corect doar dacă mediul este complet observabil.
  2. Agent reflex bazat pe model – păstrează o stare internă actualizată cu un model de tranziție (cum evoluează lumea, ce fac acțiunile mele) și un model senzorial (cum se reflectă lumea în percepții).
  3. Agent bazat pe scop – știe ce stări sunt dezirabile (scopuri) și caută/planifică secvențe de acțiuni pentru a le atinge.
  4. Agent bazat pe utilitate – o funcție de utilitate U(s) ordonează stările; alege acțiunea cu utilitate așteptată maximă. Necesar când scopurile sunt în conflict sau incerte.
  5. Agent care învață – element de performanță + critic + element de învățare + generator de probleme (explorare).
def simple_reflex_agent_program(rules, interpret_input):
    def program(percept):
        state = interpret_input(percept)          # abstractizează percepția
        rule = next(r for r in rules if r.matches(state))
        return rule.action
    return program

def model_based_agent_program(rules, update_state, transition_model, sensor_model):
    state, last_action = None, None
    def program(percept):
        nonlocal state, last_action
        state = update_state(state, last_action, percept, transition_model, sensor_model)
        rule = next(r for r in rules if r.matches(state))
        last_action = rule.action
        return last_action
    return program

Agentul bazat pe utilitate alege argmaxa Σs' P(s' | s, a) · U(s'). Agenții de căutare din §1.5 sunt agenți bazați pe scop, cu reprezentare atomică a stărilor.

Reprezentări ale stării: atomică → factorizată → structurată

  • Atomică: starea este o „cutie neagră” (un nume). Căutare, jocuri, MDP-uri simple.
  • Factorizată: starea este un vector de variabile/atribute. CSP, logică propozițională, planificare (ședințele 2–4), rețele bayesiene, algoritmi genetici (cromozomul ca vector, ședințele 4–6).
  • Structurată: obiecte și relații. Logică de ordinul I, PDDL cu variabile, grafuri de cunoștințe.

Expresivitatea crescută permite descrieri mult mai compacte, dar raționamentul devine mai costisitor. Alegerea reprezentării este prima decizie de proiectare în proiectul vostru.

Sisteme multi-agent (SMA). În medii virtuale distribuite, agenții comunică prin limbaje standard (FIPA-ACL: inform, request, propose, cfp). Platforma JADE (Bellifemine et al., 2007) implementează standardul FIPA în Java: agenți cu behaviours, pagini galbene (DF), protocoale de interacțiune (Contract Net). Revenim la agenți cooperanți la planificarea multi-agent (ședința 4).

1.5 Agenți de căutare (rezolvarea problemelor prin căutare)

Un agent bazat pe scop, într-un mediu complet observabil, determinist, cunoscut, discret, poate calcula înainte de a acționa o secvență de acțiuni care îl duce la scop. Pașii: formularea scopului → formularea problemei → căutare → execuție.

O problemă de căutare este definită de: starea inițială s0; ACTIONS(s); modelul de tranziție RESULT(s, a); testul de scop IS-GOAL(s); costul acțiunii c(s, a, s'). O soluție este un drum de la s0 la o stare-scop; soluția optimă are cost minim.

Algoritmii construiesc un arbore de căutare peste graful stărilor. Frontiera conține nodurile generate, dar neexpandate; strategia de căutare = ordinea în care alegem din frontieră.

AlgoritmFrontieraComplet?Optim?Timp / Memorie

b = factorul de ramificare, d = adâncimea soluției celei mai puțin adânci, m = adâncimea maximă, C* = costul soluției optime.

Euristici admisibile și consistente

  • Admisibilă: h(n) ≤ h*(n) pentru orice n (nu supraestimează costul real rămas).
  • Consistentă (monotonă): h(n) ≤ c(n, a, n') + h(n') și h(scop) = 0. Consistența implică admisibilitatea; cu ea, f este nedescrescătoare pe orice drum.

Pe grilă cu 4 direcții: distanța Manhattan |Δx| + |Δy| este consistentă; cu 8 direcții și cost √2 pe diagonală – distanța octilă. Euclidiana este admisibilă în ambele cazuri, dar mai puțin informată.

Dominanță: dacă h2(n) ≥ h1(n) pentru orice n și ambele sunt admisibile, A* cu h2 nu expandează niciodată mai multe noduri (până la departajări) decât cu h1. Euristici bune se obțin din probleme relaxate (eliminăm restricții) – idee reluată la planificare (ședința 2).

Schiță de demonstrație: optimalitatea A* (căutare în graf, h consistentă)

  1. Dacă h este consistentă, valorile f de-a lungul oricărui drum sunt nedescrescătoare: f(n') = g(n) + c + h(n') ≥ g(n) + h(n) = f(n).
  2. Când A* extrage un nod n din frontieră, drumul optim până la n a fost deja găsit. (Altfel, există pe drumul optim un nod n'' în frontieră cu f(n'') ≤ f(n), contradicție cu ordinea de extragere – departajare tratată separat.)
  3. Deci nodurile sunt expandate în ordinea nedescrescătoare a lui f; primul nod-scop extras are f = g = C*.

Eficiența optimă: orice algoritm care extinde drumuri de la rădăcină și folosește aceeași h trebuie să expandeze toate nodurile cu f(n) < C*. A* nu expandează niciun nod cu f(n) > C* (pruning).

Variante cu memorie limitată: IDA* (adâncire iterativă pe pragul f), RBFS, SMA*. Weighted A* (f = g + w·h, w > 1) găsește soluții de cost ≤ w·C*, mult mai repede – des folosit în jocuri și robotică.

1.6 Agenți de căutare în regim operativ (online) și în mediu necunoscut

Până acum agentul calcula întregul plan offline, apoi îl executa „cu ochii închiși”. Asta nu mai merge când:

  • mediul este necunoscut (nu știm RESULT(s, a) până nu încercăm acțiunea) – ex.: un robot într-o clădire necartografiată, un NPC într-o lume generată procedural;
  • mediul este dinamic și nu ne permitem să deliberăm mult (penalizare pentru timp);
  • mediul este nedeterminist: trebuie să vedem ce s-a întâmplat înainte de pasul următor.

Un agent de căutare online intercalează calculul și acțiunea: acționează, observă starea rezultată, își actualizează cunoștințele și abia apoi decide pasul următor.

Ce știe un agent online

Doar: ACTIONS(s) pentru starea curentă, costul c(s, a, s') – aflat după ce ajunge în s' –, IS-GOAL(s) și, eventual, o euristică admisibilă h(s). Calitatea se măsoară prin raportul competitiv = costul drumului parcurs efectiv / costul drumului optim (dacă mediul ar fi fost cunoscut).

Dificultăți

  • Fundături (dead ends): acțiuni ireversibile (o rampă pe care nu mai poți urca înapoi). Niciun algoritm nu le poate evita în toate spațiile – argument cu adversar.
  • Presupunem de obicei un spațiu sigur de explorat (safely explorable): din orice stare accesibilă se poate ajunge la scop.
  • Algoritmii care „sar” între noduri ale frontierei (A*) nu sunt potriviți: agentul ar trebui să se deplaseze fizic până acolo. Sunt preferați algoritmii locali: DFS online (cu revenire fizică), LRTA*.

LRTA* (Learning Real-Time A*)

Agentul păstrează un tabel H(s), inițializat cu h(s). La fiecare pas:

H(sprev) ← minb [ c(sprev, b, s') + H(s') ];   a ← argminb [ c(s, b, s') + H(s') ]

Acțiunile neîncercate încă sunt evaluate optimist (cu h(s)) – optimism în fața incertitudinii, care încurajează explorarea. LRTA* este complet în spații finite, sigur de explorat, și, rulat repetat, converge spre drumul optim (H converge la h* pe drumul optim).

Rezultate teoretice și legături

  • Pentru DFS online, într-un spațiu sigur de explorat cu acțiuni reversibile, fiecare muchie este traversată de cel mult două ori; dar raportul competitiv poate fi arbitrar de mare (scopul e aproape, dar agentul pleacă într-o explorare lungă).
  • O „plimbare aleatoare” este completă în spații finite sigure, dar poate avea cost exponențial (exemplul „lanțului” în care probabilitatea de a avansa scade).
  • LRTA* este un caz particular al ideii de învățare a funcției valoare; în medii stochastice generalizarea este Real-Time Dynamic Programming și, mai departe, învățarea prin întărire (Q-learning).
  • Planificarea cu replanificare (D* Lite, folosit pe roverele marțiene) reutilizează calculele anterioare când harta se modifică – foarte relevant pentru agenți în medii virtuale dinamice.

S1.2 – Adevărat sau fals? Argumentați.
  1. Un agent care percepe doar parțial starea nu poate fi perfect rațional.
  2. Există medii în care un agent reflex simplu este perfect rațional.
  3. Un agent care alege acțiuni aleatoare poate fi rațional.
  4. Un mediu complet observabil este întotdeauna determinist.
Soluție
  1. Fals. Raționalitatea se raportează la percepțiile disponibile; agentul face tot ce se poate cu ele.
  2. Adevărat. De exemplu, lumea aspiratorului cu 2 camere, complet observabilă local, fără penalizare pentru deplasări.
  3. Adevărat. În mediile în care orice acțiune este la fel de bună, sau când randomizarea evită ciclurile (agentul reflex care se blochează) ori exploatarea de către un adversar (piatră-hârtie-foarfecă).
  4. Fals. Zarul este complet observabil după aruncare, dar rezultatul acțiunii „aruncă” este stochastic.
S1.3 – Problematizare: când eșuează agentul reflex?

În lumea aspiratorului cu 2 camere, penalizăm fiecare deplasare cu −1 și recompensăm fiecare cameră curățată cu +10. (a) Este agentul reflex simplu rațional? (b) Ce agent ar fi rațional? (c) Ce se schimbă dacă murdăria reapare aleator cu probabilitatea p la fiecare pas?

Soluție

(a) Nu: după ce ambele camere sunt curate, oscilează la infinit și pierde 1 punct la fiecare pas. (b) Un agent cu model care reține că ambele camere sunt curate și execută NoOp. (c) Cu p > 0, a sta pe loc la nesfârșit nu mai e rațional: murdăria reapare. Agentul ar trebui să revină periodic, la un interval care depinde de p și de costul deplasării (decizie de tip utilitate). Experimentul din laborator (L1) confirmă: pentru p = 0 agentul cu model câștigă clar, dar pentru p = 0,1 și p = 0,3 agentul reflex obține un scor mediu mai mare – modelul „totul e curat pentru totdeauna” a devenit fals.

S1.5 – Euristică admisibilă, dar inconsistentă

(a) Construiți un graf cu 4 noduri și o euristică admisibilă, dar inconsistentă, pentru care A* în graf (cu mulțime de noduri închise, fără redeschidere) întoarce o soluție suboptimă. (b) Cum se repară algoritmul?

Soluție

Noduri S, A, B, G. Muchii: S–A cost 1, A–B cost 1, S–B cost 3, B–G cost 3. Euristica: h(S) = 0, h(A) = 4, h(B) = 0, h(G) = 0. Costurile reale până la G: h*(B) = 3, h*(A) = 4, h*(S) = 5 – deci h este admisibilă. Este inconsistentă pe muchia A–B: h(A) = 4 > c(A, B) + h(B) = 1.

(b) Fie folosim o euristică consistentă (sau corecția pathmax: f(n') = max(f(n), g(n') + h(n'))), fie permitem redeschiderea nodurilor închise când găsim un g mai mic. """Lumea aspiratorului (Russell & Norvig, cap. 2) – agent reflex simplu vs. agent bazat pe model.
Rulare: python s01_vacuum.py"""
import random

class VacuumWorld:
    """Mediu cu n camere pe o linie. Murdăria poate reapărea cu probabilitatea p_dirt."""
    def __init__(self, n=2, p_dirt=0.0, seed=0):
        self.rng = random.Random(seed)
        self.n, self.p_dirt = n, p_dirt
        self.dirty = [self.rng.random() < 0.5 for _ in range(n)]
        self.pos = self.rng.randrange(n)
        self.score = 0

    def percept(self):                      # observabilitate parțială: doar camera curentă
        return self.pos, self.dirty[self.pos]

    def execute(self, action):
        if action == "Suck":
            if self.dirty[self.pos]:
                self.score += 10            # măsura de performanță: +10 pentru fiecare cameră curățată
            self.dirty[self.pos] = False
        elif action == "Left" and self.pos > 0:
            self.pos -= 1; self.score -= 1  # -1 pentru fiecare deplasare (consum de energie)
        elif action == "Right" and self.pos < self.n - 1:
            self.pos += 1; self.score -= 1
        for i in range(self.n):             # mediu dinamic: murdăria poate reapărea
            if self.rng.random() < self.p_dirt:
                self.dirty[i] = True

def simple_reflex_agent(percept):
    """Regulă condiție-acțiune: decide DOAR pe baza percepției curente."""
    pos, dirty = percept
    if dirty:
        return "Suck"
    return "Right" if pos == 0 else "Left"   # pentru n = 2

class ModelBasedAgent:
    """Păstrează o stare internă (ce camere știe că sunt curate) și se oprește când totul e curat."""
    def __init__(self, n):
        self.known_clean = [False] * n
        self.direction = "Right"
    def __call__(self, percept):
        pos, dirty = percept
        if dirty:
            self.known_clean[pos] = True
            return "Suck"
        self.known_clean[pos] = True
        if all(self.known_clean):
            return "NoOp"                    # nu mai consumă energie inutil
        n = len(self.known_clean)
        if pos == n - 1: self.direction = "Left"
        if pos == 0: self.direction = "Right"
        return self.direction

def run(agent, env, steps=20, verbose=False):
    for t in range(steps):
        p = env.percept()
        a = agent(p)
        env.execute(a)
        if verbose:
            print(f"t={t:2d} percepție={p} acțiune={a:5s} scor={env.score}")
    return env.score

if __name__ == "__main__":
    for p_dirt in (0.0, 0.05):
        r1 = sum(run(simple_reflex_agent, VacuumWorld(2, p_dirt, s)) for s in range(100)) / 100
        r2 = sum(run(ModelBasedAgent(2), VacuumWorld(2, p_dirt, s)) for s in range(100)) / 100
        print(f"p_dirt={p_dirt:.2f}  reflex simplu: {r1:6.2f}   bazat pe model: {r2:6.2f}")

L1.2 – Agenți de căutare pe grilă

Codul de mai jos formulează problema (clasa GridProblem) și implementează BFS, DFS și o schemă generală best-first din care obținem UCS, Greedy și A*.

"""Agenți de căutare pe grilă: BFS, DFS, UCS, Greedy și A*.
'#' = zid, '~' = mlaștină (cost 5), 'S' = start, 'G' = țintă.  Rulare: python s01_grid_search.py"""
import heapq
from collections import deque

GRID = """
S....#........
.##..#..~~~...
..#..#..~~~.#.
..#.....~~~.#.
..####..#...#.
.....#..#..##G
""".strip().splitlines()

class GridProblem:
    """Formularea problemei: stare inițială, acțiuni, model de tranziție, test de scop, cost."""
    MOVES = {"N": (-1, 0), "S": (1, 0), "V": (0, -1), "E": (0, 1)}
    def __init__(self, grid):
        self.grid = grid
        self.R, self.C = len(grid), len(grid[0])
        for r, row in enumerate(grid):
            for c, ch in enumerate(row):
                if ch == "S": self.initial = (r, c)
                if ch == "G": self.goal = (r, c)
    def actions(self, s):
        r, c = s
        for a, (dr, dc) in self.MOVES.items():
            nr, nc = r + dr, c + dc
            if 0 <= nr < self.R and 0 <= nc < self.C and self.grid[nr][nc] != "#":
                yield a, (nr, nc)
    def cost(self, s, a, s2):
        return 5 if self.grid[s2[0]][s2[1]] == "~" else 1
    def is_goal(self, s):
        return s == self.goal
    def h(self, s):                       # distanța Manhattan: admisibilă și consistentă (cost minim pe pas = 1)
        return abs(s[0] - self.goal[0]) + abs(s[1] - self.goal[1])

def path_from(parent, s):
    path = [s]
    while parent[s] is not None:
        s = parent[s]; path.append(s)
    return path[::-1]

def bfs(p):
    frontier, parent, expanded = deque([p.initial]), {p.initial: None}, 0
    while frontier:
        s = frontier.popleft(); expanded += 1
        if p.is_goal(s): return path_from(parent, s), expanded
        for a, s2 in p.actions(s):
            if s2 not in parent:
                parent[s2] = s; frontier.append(s2)
    return None, expanded

def dfs(p):
    frontier, parent, expanded, seen = [p.initial], {p.initial: None}, 0, set()
    while frontier:
        s = frontier.pop()
        if s in seen: continue
        seen.add(s); expanded += 1
        if p.is_goal(s): return path_from(parent, s), expanded
        for a, s2 in p.actions(s):
            if s2 not in seen:
                parent[s2] = s; frontier.append(s2)
    return None, expanded

def best_first(p, f):
    """Schema generală best-first; f(g, s) dă prioritatea. UCS: f=g; Greedy: f=h; A*: f=g+h."""
    g = {p.initial: 0}; parent = {p.initial: None}
    frontier = [(f(0, p.initial), 0, p.initial)]; expanded = 0; tie = 0
    closed = set()
    while frontier:
        _, _, s = heapq.heappop(frontier)
        if s in closed: continue          # intrare învechită în coadă
        closed.add(s); expanded += 1
        if p.is_goal(s): return path_from(parent, s), expanded   # testul de scop la EXTRAGERE!
        for a, s2 in p.actions(s):
            g2 = g[s] + p.cost(s, a, s2)
            if s2 not in g or g2 < g[s2]:
                g[s2] = g2; parent[s2] = s; tie += 1
                heapq.heappush(frontier, (f(g2, s2), tie, s2))
    return None, expanded

def path_cost(p, path):
    return sum(p.cost(path[i], None, path[i + 1]) for i in range(len(path) - 1))

if __name__ == "__main__":
    P = GridProblem(GRID)
    algos = {
        "BFS": lambda: bfs(P),
        "DFS": lambda: dfs(P),
        "UCS": lambda: best_first(P, lambda g, s: g),
        "Greedy": lambda: best_first(P, lambda g, s: P.h(s)),
        "A*": lambda: best_first(P, lambda g, s: g + P.h(s)),
    }
    print(f"{'Algoritm':8s} {'expandate':>9s} {'pași':>5s} {'cost':>5s}")
    for name, run in algos.items():
        path, exp = run()
        print(f"{name:8s} {exp:9d} {len(path)-1:5d} {path_cost(P, path):5d}")

L1.3 – Agent online LRTA* în mediu necunoscut

Agentul nu cunoaște harta: percepe doar direcțiile libere din celula curentă și învață H(s). Rulat de mai multe ori pe aceeași hartă (păstrând H), converge spre un drum cu număr minim de pași.

"""Agent de căutare ONLINE (LRTA*) într-un mediu NECUNOSCUT.
Agentul nu cunoaște harta: la fiecare pas percepe doar vecinii accesibili ai celulei curente,
acționează imediat și își actualizează estimarea H(s) a costului până la țintă.
Rulare: python s01_lrta.py"""
from s01_grid_search import GRID, GridProblem, bfs

class LRTAStarAgent:
    def __init__(self, goal):
        self.goal = goal
        self.H = {}                         # estimările învățate H(s)
        self.result = {}                    # modelul de tranziție învățat: (s, a) -> s'
        self.s = self.a = None
    def h(self, s):
        return abs(s[0] - self.goal[0]) + abs(s[1] - self.goal[1])
    def lrta_cost(self, s, s2):
        if s2 is None:                      # rezultat încă necunoscut: optimism față de necunoscut
            return self.h(s)
        return 1 + self.H.get(s2, self.h(s2))
    def __call__(self, s, available_actions):
        if s == self.goal:
            return None
        self.H.setdefault(s, self.h(s))
        if self.s is not None:
            self.result[(self.s, self.a)] = s
            # actualizare: H(s_prev) = min_b cost(s_prev, b)
            self.H[self.s] = min(self.lrta_cost(self.s, self.result.get((self.s, b)))
                                 for b in self.prev_actions)
        self.a = min(available_actions,
                     key=lambda b: self.lrta_cost(s, self.result.get((s, b))))
        self.s, self.prev_actions = s, list(available_actions)
        return self.a

def explore(problem, agent, max_steps=2000):
    """Mediul: execută acțiunea și îi întoarce agentului doar percepția locală."""
    s, steps, trace = problem.initial, 0, [problem.initial]
    while steps < max_steps:
        moves = dict(problem.actions(s))    # percepție locală: ce direcții sunt libere
        a = agent(s, list(moves))
        if a is None:
            return steps, trace
        s = moves[a]; steps += 1; trace.append(s)
    return None, trace

if __name__ == "__main__":
    P = GridProblem(GRID)
    opt_path, _ = bfs(P)   # LRTA* de aici numără pașii (cost unitar)
    agent = LRTAStarAgent(P.goal)
    for trial in range(1, 6):              # rulări repetate: agentul își păstrează H (învață)
        steps, _ = explore(P, agent)
        print(f"încercarea {trial}: {steps} pași  (minimul offline, cu harta cunoscută: {len(opt_path)-1})")
        agent.s = agent.a = None

import heapq

def astar(problem):
    frontier = [(0, problem.initial)]
    g = {problem.initial: 0}
    parent = {problem.initial: None}
    visited = set()
    while frontier:
        f, s = heapq.heappop(frontier)
        visited.add(s)
        for a, s2 in problem.actions(s):
            if problem.is_goal(s2):
                parent[s2] = s
                return s2, parent
            if s2 in visited:
                continue

            parent[s2] = s
            h = ((s2[0]-problem.goal[0])**2 + (s2[1]-problem.goal[1])**2)
