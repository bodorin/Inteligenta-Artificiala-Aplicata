2. Învățarea supervizată pentru control: clonarea comportamentului

Începător

Un om (sau un controler expert) conduce robotul; înregistrăm (observație, acțiune) și antrenăm un model care imită expertul. Simplu și eficient – dar cu o capcană: dacă robotul ajunge într-o situație pe care expertul nu a demonstrat-o (puțin în afara drumului), modelul nu știe ce să facă, greșește și mai mult, și erorile se acumulează.

Mediu

Formal, modelul este antrenat pe distribuția stărilor expertului dπ*, dar evaluat pe distribuția stărilor proprii dπ (covariate shift). Eroarea poate crește cu O(T²) în orizontul T (Ross & Bagnell). DAgger (Dataset Aggregation): rulează politica învățată, cere expertului etichete pe stările vizitate de ea, adaugă la set, reantrenează – eroarea devine O(T).

Demonstrație: clonarea comportamentului vs. DAgger (urmărirea unei benzi)

Stare: abaterea laterală e și unghiul ψ față de bandă. Expertul: ω = −k1e − k2ψ. Elevul: regresie k-NN pe demonstrații. Demonstrațiile inițiale acoperă doar stări apropiate de centru.

Avansat

Variante moderne: Diffusion Policy și Action Chunking Transformers (prezic secvențe de acțiuni, modelează distribuții multimodale ale demonstrațiilor), teleoperare cu dispozitive de tip leader-follower pentru colectarea datelor de manipulare; modele de fundație antrenate pe seturi mari multi-robot și ajustate pe sarcini specifice. Limitele rămân: datele de demonstrație sunt scumpe, iar garanțiile de siguranță sunt dificile.

3. Învățarea prin consolidare: fundamente

Mediu

Scopul: maximizarea randamentului – suma recompenselor viitoare, cu cele îndepărtate cântărite mai puțin (factor de discount γ ∈ [0, 1)):

Gt = rt+1 + γ rt+2 + γ² rt+3 + … = Σk≥0 γk rt+k+1
Mediu

Un MDP este ⟨S, A, P, R, γ⟩. Funcția de valoare a acțiunii Qπ(s, a) = E[Gt | st=s, at=a]. Valoarea optimă satisface ecuația Bellman de optimalitate:

Q*(s, a) = E[ r + γ · maxa′ Q*(s′, a′) ]

Q-learning (off-policy, fără model) aproximează Q* din experiență:

Q(s, a) ← Q(s, a) + α [ r + γ · maxa′ Q(s′, a′) − Q(s, a) ]

Explorarea ε-greedy: cu probabilitatea ε acțiune aleatoare, altfel cea mai bună acțiune cunoscută; ε scade de-a lungul antrenării.

Gridworld: Q-learning în timp real

Robotul (cerc) învață să ajungă la țintă (verde, +10) evitând gropile (roșu, −10); fiecare pas costă −0,1. Săgețile arată politica greedy, culoarea – valoarea maxa Q(s, a). Opțional: acțiunile „alunecă” (mediu stocastic).

Avansat

Convergența Q-learning tabular la Q* este garantată în condiții Robbins–Monro (Σα = ∞, Σα² < ∞, toate perechile vizitate infinit de des). Cu γ mic, agentul devine miop (nu „vede” ținta îndepărtată și preferă să evite gropile stând pe loc). Cu alunecare, politica optimă ocolește gropile la distanță mai mare – diferența dintre Q-learning (off-policy, învață politica optimă greedy, „riscantă”) și SARSA (on-policy, învață o politică mai prudentă sub explorare) – exemplul clasic „cliff walking” din Sutton & Barto.

Proiectarea recompensei și a observațiilor

  • Recompensă rară (doar +1 la țintă) – corectă, dar greu de învățat; recompensă modelată (progres spre țintă, penalizări de coliziune, de efort, de smucituri) – învățare rapidă, dar risc de reward hacking (agentul exploatează formula: de ex. oscilează lângă țintă ca să colecteze progres). Modelarea bazată pe potențial (F = γΦ(s′) − Φ(s)) păstrează politica optimă.
  • Observații: relative la robot (distanța și unghiul spre țintă, nu coordonate absolute), normalizate; istoric scurt pentru viteze; aceleași observații trebuie să existe și pe robotul real.
  • Acțiuni: comenzi de nivel mediu (v, ω sau ținte pentru PD la articulații) – mai ușor de învățat și mai sigure decât cupluri brute.
Avansat
  • Simulare masiv paralelă pe GPU (Isaac Lab, MuJoCo/MJX, Genesis etc.): mii de medii simultan → politici de locomoție în minute/ore.
  • Curriculum: sarcini din ce în ce mai grele (teren, viteze). Asymmetric actor-critic: criticul vede starea privilegiată din simulator, actorul doar observațiile reale. Teacher–student: profesorul cu informație privilegiată, elevul distilat pe senzori reali.
  • Evaluare corectă: mai multe semințe aleatoare (≥ 5), intervale de încredere, metrici robuste (IQM), separarea mediilor de antrenare și de test; RL este notoriu de sensibil la hiperparametri.

5. Antrenarea în simulare și transferul pe robotul real (sim-to-real)

Începător

RL are nevoie de milioane de încercări – pe un robot real ar dura luni și l-ar distruge. De aceea se antrenează în simulare. Problema: simulatorul nu este identic cu realitatea (frecări, mase, întârzieri, zgomotul senzorilor, aspectul imaginilor) – reality gap. O politică „perfectă” în simulare poate eșua pe robot.

Mediu
StrategieIdee

Observații robusteEvităm intrările greu de simulat; adăugăm zgomot și întârzieri realiste

Demonstrație: randomizarea domeniului

Sarcină: un controler PD duce un robot (masă punctuală pe o axă) la poziția 1 m. Căutăm câștigurile (Kp, Kd) care minimizează costul (eroare + efort) (a) în simulatorul nominal, (b) pe o distribuție randomizată de parametri. Apoi evaluăm pe „robotul real”, cu parametri necunoscuți la antrenare.

Avansat

Randomizarea prea largă produce politici conservatoare (performanță medie mai slabă); prea îngustă – fragile. Soluții: randomizare automată adaptivă (ADR – lărgirea treptată a intervalelor cât timp performanța rămâne bună), politici condiționate de parametri estimați, identificarea sistemului în buclă (real-to-sim-to-real). Evaluarea transferului cere protocoale riguroase pe robotul real (număr de încercări, condiții, criterii de eșec), nu doar demonstrații video selectate.

Seminar 7 – Învățare automată în robotică

Problema 1 – Randamentul actualizat

Începător

Recompense: −1, −1, −1, +10 (episod încheiat). Calculați G0 pentru γ = 1, γ = 0,9 și γ = 0,5. Ce observați?

Soluție

γ = 1: 7. γ = 0,9: −1 − 0,9 − 0,81 + 7,29 = 4,58. γ = 0,5: −1 − 0,5 − 0,25 + 1,25 = −0,5. Cu γ mic, recompensa îndepărtată contează puțin – agentul devine „miop”; un drum lung spre țintă poate părea mai prost decât a nu face nimic.

Problema 2 – Actualizare Q-learning

Mediu

Q(s, dreapta) = 2,0; α = 0,5; γ = 0,9. Agentul face „dreapta”, primește r = −0,1 și ajunge în s′ cu Q(s′, ·) = [1,0; 4,0; 3,0; 0,5]. Calculați noul Q(s, dreapta). Ce valoare ar folosi SARSA dacă următoarea acțiune aleasă (ε-greedy) ar fi cea cu Q = 1,0?

Soluție

Țintă Q-learning: −0,1 + 0,9·4,0 = 3,5; Q ← 2,0 + 0,5·(3,5 − 2,0) = 2,75. SARSA: țintă −0,1 + 0,9·1,0 = 0,8; Q ← 2,0 + 0,5·(0,8 − 2,0) = 1,4.

Problema 3 – Explorare

Începător

Cu 4 acțiuni și ε = 0,2, care este probabilitatea de a alege acțiunea greedy? De ce nu folosim ε = 0 de la început?

Soluție

(1 − 0,2) + 0,2/4 = 0,85. Cu ε = 0, agentul exploatează estimările inițiale (adesea greșite) și poate să nu descopere niciodată drumuri mai bune.

Problema 4 – Dimensiunea tabelului Q

Mediu

Un robot are ca observație 8 raze LiDAR, fiecare discretizată în 5 niveluri, plus unghiul spre țintă în 8 sectoare. Acțiuni: 5. Câte intrări are tabelul Q? Concluzie?

Soluție

5⁸·8·5 = 390 625·40 = 15 625 000 intrări – majoritatea nevizitate vreodată. Concluzie: aproximarea funcției (rețele neuronale – DQN/PPO), care generalizează între stări similare.

Problema 5 – Reward hacking

Mediu

Recompensa unui robot de navigație: +1 pentru fiecare pas în care distanța la țintă scade, −100 la coliziune. După antrenare, robotul oscilează înainte și înapoi lângă start. Explicați și propuneți o recompensă mai bună.

Soluție

Oscilația produce pași alternativi „în progres” (+1) fără penalizare pentru pașii de regres; în plus, riscul de coliziune pe drum descurajează avansul. Recompensă bazată pe potențial: r = k·(dt−1 − dt) (pozitivă la apropiere, negativă la îndepărtare – suma telescopică nu poate fi „păcălită”), + bonus la țintă, − cost de timp, − penalizare de coliziune proporționată.

Problema 6 – Clonarea comportamentului

Mediu

Un model antrenat pe 2 ore de conducere umană pe centrul benzii iese de pe bandă după câteva secunde în test. De ce? Propuneți două remedii.

Soluție

Covariate shift: modelul nu a văzut niciodată stări cu abatere mare și acțiunile de corecție. Remedii: DAgger (expertul etichetează stările vizitate de model); colectarea intenționată de date de recuperare (demonstrații care pornesc din stări perturbate; augmentări de tip camere laterale cu etichete de corecție); antrenarea cu zgomot injectat în acțiuni (DART).

import numpy as np, gymnasium as gym, matplotlib.pyplot as plt
env = gym.make('FrozenLake-v1', map_name='4x4', is_slippery=True)
Q = np.zeros((env.observation_space.n, env.action_space.n))
alpha, gamma, eps, eps_min, decay = 0.1, 0.99, 1.0, 0.05, 0.9995
rng = np.random.default_rng(0); returns = []
for ep in range(20000):
    s, _ = env.reset(seed=int(rng.integers(1e9))); done = False; G = 0.0
    while not done:
        a = env.action_space.sample() if rng.random() < eps else int(np.argmax(Q[s]))
        s2, r, term, trunc, _ = env.step(a); done = term or trunc
        target = r + (0 if term else gamma * np.max(Q[s2]))
        Q[s, a] += alpha * (target - Q[s, a]); s = s2; G += r
    eps = max(eps_min, eps * decay); returns.append(G)
w = 500; plt.plot(np.convolve(returns, np.ones(w)/w, mode='valid'))
plt.xlabel('episod'); plt.ylabel(f'rată de succes (medie mobilă {w})'); plt.grid(); plt.show()
print(np.argmax(Q, axis=1).reshape(4, 4))      # 0=stânga 1=jos 2=dreapta 3=sus

Partea B – Mediu propriu: navigarea unui robot diferențial

# diffdrive_env.py
import numpy as np, gymnasium as gym
from gymnasium import spaces

class DiffDriveNav(gym.Env):
    """Robot diferențial într-o arenă 6x6 m cu obstacole circulare aleatoare.
    Observație: [d_țintă/6, sin α, cos α, v/vmax, ω/ωmax, 12 raze/rmax]; acțiune continuă [v, ω] în [-1, 1]."""
    metadata = {'render_modes': []}
    def __init__(self, n_obs=5, rand=0.0, max_steps=400):
        self.n_obs, self.rand, self.max_steps = n_obs, rand, max_steps
        self.vmax, self.wmax, self.dt, self.R, self.rmax, self.nr = 0.25, 1.8, 0.1, 0.12, 2.0, 12
        self.action_space = spaces.Box(-1.0, 1.0, (2,), np.float32)
        self.observation_space = spaces.Box(-1.0, 1.0, (5 + self.nr,), np.float32)

    def _rays(self):
        angs = self.th + np.linspace(-np.pi, np.pi, self.nr, endpoint=False)
        out = np.full(self.nr, self.rmax)
        for i, a in enumerate(angs):
            d = np.array([np.cos(a), np.sin(a)])
            for (ox, oy, r) in self.obs:                         # intersecție rază–cerc
                f = self.p - (ox, oy); b = f @ d; c = f @ f - r * r; disc = b * b - c
                if disc >= 0:
                    t = -b - np.sqrt(disc)
                    if 0 < t < out[i]: out[i] = t
            for k in range(2):                                   # pereții arenei [0, 6]
                if abs(d[k]) > 1e-9:
                    for wall in (0.0, 6.0):
                        t = (wall - self.p[k]) / d[k]
                        if 0 < t < out[i]: out[i] = t
        noise = self.np_random.normal(0, 0.02 + 0.03 * self.rand, self.nr)   # zgomot de senzor
        return np.clip(out + noise, 0, self.rmax)

    def _obs(self):
        dvec = self.goal - self.p; dist = np.linalg.norm(dvec)
        al = np.arctan2(dvec[1], dvec[0]) - self.th
        o = np.concatenate([[min(dist / 6, 1), np.sin(al), np.cos(al), self.v / self.vmax, self.w / self.wmax],
                            self._rays() / self.rmax])
        return np.clip(o, -1.0, 1.0).astype(np.float32)          # cu randomizare, v/vmax poate depăși 1

    def reset(self, seed=None, options=None):
        super().reset(seed=seed); rng = self.np_random
        self.p = rng.uniform(0.5, 1.5, 2); self.goal = rng.uniform(4.5, 5.5, 2)
        self.th = rng.uniform(-np.pi, np.pi); self.v = self.w = 0.0; self.t = 0
        self.obs = []
        while len(self.obs) < self.n_obs:
            o = (*rng.uniform(1.5, 4.5, 2), rng.uniform(0.2, 0.45))
            if np.linalg.norm(np.array(o[:2]) - self.goal) > o[2] + 0.4: self.obs.append(o)
        self.gain = 1.0 + self.rand * rng.uniform(-0.3, 0.3)     # randomizare: câștigul actuatorului
        self.prev_d = np.linalg.norm(self.goal - self.p)
        return self._obs(), {}

    def step(self, action):
        a = np.clip(action, -1, 1)
        v_cmd, w_cmd = (a[0] + 1) / 2 * self.vmax * self.gain, a[1] * self.wmax * self.gain
        self.v += np.clip(v_cmd - self.v, -0.05, 0.05); self.w += np.clip(w_cmd - self.w, -0.4, 0.4)   # accelerații limitate
        self.th += self.w * self.dt
        self.p = self.p + self.v * self.dt * np.array([np.cos(self.th), np.sin(self.th)]); self.t += 1
        d = np.linalg.norm(self.goal - self.p)
        collided = any(np.linalg.norm(self.p - (ox, oy)) < r + self.R for ox, oy, r in self.obs) \
                   or np.any(self.p < self.R) or np.any(self.p > 6 - self.R)
        reward = 5.0 * (self.prev_d - d) - 0.01 - 0.02 * abs(a[1])   # progres − timp − efort
        self.prev_d = d
        terminated = False
        if collided: reward -= 10.0; terminated = True
        if d < 0.25: reward += 10.0; terminated = True
        truncated = self.t >= self.max_steps
        return self._obs(), float(reward), terminated, truncated, {'success': d < 0.25, 'collision': collided}

# evaluate.py
import numpy as np
from stable_baselines3 import PPO
from diffdrive_env import DiffDriveNav

def evaluate(policy_fn, n=200, rand=0.0, seed=1000):
    env = DiffDriveNav(rand=rand); succ = coll = 0; lens = []
    for i in range(n):
        o, _ = env.reset(seed=seed + i); done = False; k = 0
        while not done:
            o, r, term, trunc, info = env.step(policy_fn(o)); done = term or trunc; k += 1
        succ += info['success']; coll += info['collision']; lens.append(k)
    return succ / n, coll / n, np.mean(lens)

model = PPO.load('ppo_diffdrive')
ppo = lambda o: model.predict(o, deterministic=True)[0]
ANG = np.linspace(-np.pi, np.pi, 12, endpoint=False)         # unghiurile razelor (indice 6 = înainte)
def baseline(o):                                    # reper reactiv: atracție spre țintă + respingere de la raze
    sin_a, cos_a, rays = o[1], o[2], o[5:] * 2.0    # raze în metri
    rep = np.sum(-np.sin(ANG) * np.clip(0.5 - rays, 0, None) / 0.5 * (np.abs(ANG) < 1.6)) * 2.5
    w = np.clip(1.5 * np.arctan2(sin_a, cos_a) + rep, -1.8, 1.8) / 1.8
    v = np.clip((rays[4:9].min() - 0.2) / 0.5, 0, 1)
    return np.array([2 * v - 1, w], np.float32)
